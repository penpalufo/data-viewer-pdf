# Excel Data Viewer 仕様書

## 1. 文書情報

| 項目 | 内容 |
|---|---|
| アプリ名 | Excel Data Viewer |
| バージョン | 0.3.1 |
| リリース日 | 2026-09-29 |
| 実行方式 | ローカルWebアプリ |
| 主な用途 | Excelデータの閲覧、検索、編集、再保存 |

## 2. 概要

Excelファイルをブラウザへドラッグ＆ドロップ、またはファイル選択で読み込み、シート単位で表として閲覧するアプリです。

選択した列に対する正規表現検索、セル内容の全文表示・編集、直前行から値が変化したセルの強調表示、編集済みExcelの保存ができます。

Excelデータはサーバーへ送信せず、ブラウザ内で処理します。

## 3. 使用技術

| 技術 | 用途 |
|---|---|
| HTML | 画面構造 |
| CSS | 画面デザイン、固定見出し、モーダル、差分強調 |
| JavaScript（ES Modules） | 機能別に分割したアプリの処理 |
| Vue 3 | Options APIによる画面状態とイベントの管理 |
| SheetJS | Excelの読み込み、編集内容の反映、Excel出力 |
| VS Code PHP Server | ローカルWebサーバー |

Vue 3とSheetJSはCDNから読み込まず、`vendor`ディレクトリ内のローカルファイルを使用します。

## 5. コーディング規則

- Vue 3はComposition APIではなくOptions APIを使用します。
- JavaScriptはES Modulesを使用し、機能別に分割します。
- Vueの状態は`app.js`へ集約し、各モジュールは純粋関数を中心にします。
- HTML、CSS、JavaScriptのインデントにはタブを使用します。
- タブ幅は4とします。
- コードはできる限りシンプルで分かりやすくします。
- 各ファイルには、処理の目的を説明する日本語コメントを記述します。
- アプリのバージョンは`app.js`の`APP_VERSION`で管理します。
- 変更内容は`app.js`先頭のバージョン履歴へ記録します。

## 6. 対応ファイル

- `.xlsx`
- `.xls`

上記以外のファイルが指定された場合は、エラーメッセージを表示して読み込みません。

## 7. Excelの読み込み

### 7.1 読み込み方法

- ドラッグ＆ドロップ
- 「ファイルを選択」ボタン

### 7.2 読み込み処理

1. ファイルの拡張子を確認します。
2. ファイルを`ArrayBuffer`として読み込みます。
3. SheetJSでワークブックへ変換します。
4. 元のワークブックをブラウザ内に保持します。
5. シート名一覧を取得します。
6. 最初のシートを初期表示します。

すべてのシートを1つの表へ結合しません。

## 8. シート選択

- Excel内の全シート名をプルダウンへ表示します。
- 選択したシートだけを表として展開します。
- シートを切り替えると、検索条件をクリアします。
- 空のシートを選択した場合は、データ表を表示しません。
- Excelのシート名とシート順は、保存時も維持します。

## 9. 表示する表

### 9.1 見出し

- 選択したシートの1行目を見出しとして扱います。
- 空の見出しには`列1`、`列2`のような仮の名前を表示します。
- 見出し行は、表を縦方向へスクロールしても常に表示します。

### 9.2 行番号

- 左端にExcel上の行番号を表示します。
- 1行目は見出しのため、最初のデータ行は`2`になります。
- 行番号列は、表を横方向へスクロールしても固定表示します。

### 9.3 セル表示

- 長い文字列はセル幅に合わせて省略し、末尾を`…`で表示します。
- 表は縦横にスクロールできます。
- 日付は日本語の日付形式で表示します。

### 9.4 描画件数

- 画面へ一度に描画する行数は最大5,000行です。
- 5,000行を超えるデータも、ブラウザ内には保持します。
- Excel保存時は、画面に表示されていない行も保存対象です。
- 検索結果が5,000行以下の場合は、検索結果をすべて表示します。

描画制限は、初期表示、検索、スクロール、シート切り替えなどの操作性を保つために設けます。

## 10. 正規表現検索

### 10.1 検索方法

検索条件は固定2セットです。それぞれに「検索する列」と「正規表現」があります。

1. 条件1の「検索する列」と「正規表現」を入力します。
2. 必要に応じて条件2の「検索する列」と「正規表現」を入力します。
3. 条件が2つ入力されている場合は、両方に一致する行だけを表示します。
4. 入力と同時に表を絞り込みます。

画面には「固定2条件のAND検索」と、条件2が空欄の場合は条件1だけで検索することを表示します。

### 10.2 検索仕様

- 検索対象は、選択中のシートと各条件で選択した列です。
- 条件1だけが入力されている場合は、条件1だけで検索します。
- 条件2が空欄の場合は、条件2を無視します。
- 条件1と条件2が入力されている場合は、AND検索します。
- 2つの条件で同じ列を選択することもできます。
- 初期状態では大文字と小文字を区別しません。
- 「大文字・小文字を区別」を選択すると、文字の大小を区別します。
- 両方の検索欄が空の場合は、すべての行を表示します。
- どちらかの正規表現が不正な場合は、該当条件と結果欄にエラーを表示し、すべての行を表示します。
- 大文字と小文字の区別設定は、2つの条件で共通です。
- 「クリア」で両方の検索文字列を削除します。
- 元のデータは変更せず、表示する行だけを絞り込みます。

### 10.3 正規表現の例

| 入力 | 意味 |
|---|---|
| `チェア` | 「チェア」を含む |
| `チェア\|ソファ` | 「チェア」または「ソファ」を含む |
| `^DP.+E$` | `DP`で始まり、途中に1文字以上あり、`E`で終わる |
| `^DP.*E$` | `DP`で始まり、途中が0文字以上で、`E`で終わる |
| `^[0-9]+$` | 数字だけで構成される |

## 11. セル内容の全文表示と編集

### 11.1 モーダル表示

- データセルをクリックすると編集モーダルを表示します。
- 短い値と省略表示された長い値のどちらも同じ方法で開きます。
- モーダルには次の情報を表示します。
  - シート名
  - Excel上のセル番地
  - 見出し名
  - セルの全文

### 11.2 編集操作

- テキストエリアで全文を編集できます。
- 改行を含む文字列も編集できます。
- 「反映」で変更を表と元のExcelシートへ反映します。
- `Ctrl + Enter`でも変更を反映できます。
- 「キャンセル」「×」、背景部分のクリック、`Esc`キーでは変更せずに閉じます。
- 同じセルを複数回編集しても、編集セル数は1セルとして数えます。

### 11.3 値の型

編集内容は次の規則で変換します。

| 入力 | 保存する型 |
|---|---|
| 空文字 | 空セル |
| 数字だけの値 | 数値 |
| `true`または`false` | 真偽値 |
| `=`で始まる値 | Excel数式 |
| その他 | 文字列 |

編集対象セルに書式情報がある場合は、可能な範囲で書式を残したまま値を書き換えます。

## 12. 直前行から変化したセルの強調

### 12.1 対象列の選択

- Excel読み込み後に「変化を強調する列」パネルを使用できます。
- 見出し一覧から複数列を選択できます。
- 初期状態ではすべて未選択です。
- 「すべて選択」で現在のシートにある全列を選択します。
- 「すべて解除」で現在のシートの選択を解除します。
- 選択中の列数をパネルのボタンに表示します。
- 対象列の選択状態はシートごとに保持します。

### 12.2 比較方法

- 選択した列だけを比較します。
- 現在行の値と、元のExcel上の直前行にある同じ列の値を比較します。
- 値が異なる場合は、現在行のセル背景を黄色で強調します。
- 最初のデータ行には直前行がないため、背景色を付けません。
- 空欄から値あり、値ありから空欄への変化も差分として扱います。
- 数値と文字列は別の値として扱います。
- 日付は日時の値で比較します。
- セルを編集した場合は、強調箇所を即時に再判定します。
- 検索で行が非表示になっても、比較対象は元のExcel上の直前行です。

## 13. Excel保存

### 13.1 保存方法

- 「Excelを保存」ボタンで編集済みファイルをダウンロードします。
- PHPによるサーバー保存は行いません。
- SheetJSを使用し、ブラウザ内でExcelファイルを生成します。
- 元ファイルを直接上書きしません。

出力ファイル名は次の形式です。

```text
元のファイル名_編集済み.xlsx
```

### 13.2 保存内容

- 元のワークブックに存在するすべてのシートを保存します。
- シート名とシート順を維持します。
- 編集対象以外のシートも保存します。
- 選択中のシートだけでなく、すべてのシートを含めます。
- 画面へ描画されていない行も含めます。
- 編集内容は該当するシートとセルへ反映します。

## 14. ローカル実行

VS Codeで`data-viewer`ディレクトリを開き、PHP Serverのドキュメントルートとして起動します。

PHPコードは使用せず、PHP ServerをHTML、CSS、JavaScript、ライブラリファイルの配信にだけ使用します。

Vue 3とSheetJSをローカルに保存しているため、アプリ本体はインターネット接続なしで動作します。

## 15. エラー表示

次の場合は画面上へエラーを表示します。

- `.xlsx`または`.xls`以外のファイルを選択した場合
- Excelファイルを解析できない場合
- Excel内にシートが存在しない場合
- 正規表現が正しくない場合

Excel読み込み中は、重複操作を防ぐためファイル選択を無効にします。

## 16. 制限事項

SheetJSの無償版を使用するため、次の内容は完全に維持できない場合があります。

- 複雑なセル書式
- 条件付き書式
- 画像
- 図形
- グラフ
- コメント
- マクロ
- 一部のセル結合、列幅、行高

数式は保存できますが、ブラウザ上でExcelと同じ再計算処理は行いません。計算結果の更新は、保存後にExcelでファイルを開いた際の再計算に依存します。
