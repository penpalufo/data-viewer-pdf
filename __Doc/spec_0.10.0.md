# Excel Data Viewer 仕様書

## 1. 文書情報

| 項目 | 内容 |
|---|---|
| アプリ名 | Excel Data Viewer |
| バージョン | 0.10.0 |
| リリース日 | 2026-10-08 |
| 実行方式 | ローカルWebアプリ |

## 2. 概要

従来のExcel閲覧、検索、編集、保存機能に加え、Excelと同じベース名のPDFおよび座標JSONがある場合は、表とPDFを左右に表示します。表のセルへマウスを重ねると、座標JSONに記録されたPDF上の位置をマーカーで示します。

## 3. ファイル構成

3ファイルのベース名を揃えます。

```text
YOZ005-25D_0319.xlsx
YOZ005-25D_0319.pdf
YOZ005-25D_0319.json
```

- 「フォルダーを選択」またはフォルダーのドラッグ＆ドロップで読み込みます。
- 選択したフォルダー内のExcelを起点に、同じディレクトリにある同名のPDFとJSONを探します。
- Webアプリを配信しているURLからPDFやJSONを自動取得しません。
- PDFとJSONの両方を読み込めた場合だけPDF連動を有効にします。
- PDFまたはJSONのどちらかがない場合は、エラーにせずExcel単体モードで動作します。
- 対象フォルダーにExcelが複数ある場合は、対象を特定できないためエラーを表示します。

## 4. PDF表示

- PDF.jsをローカルの`vendor/pdfjs`から読み込みます。
- Excel単体モードでは、表を従来どおり全幅で表示します。
- PDF連動時は、左半分へExcel表、右半分へPDFを表示します。
- 狭い画面では表とPDFを上下に配置します。
- 「表示を合わせる」でPDFを表示領域の幅に合わせて再描画します。

## 5. 座標JSON

対応するJSONは次の条件を満たすものとします。

- `v`は`2`
- `coordinate_system`は`pdf_points_top_left`
- `point_rule`は`bbox_center`
- `pdf`は同名PDFのファイル名
- `size`はPDFページの幅と高さ
- `sheets`内にシート名、Excel行番号、列ごとの中心座標がある

JSONの`workbook`は生成元ファイル名の参考情報として扱います。配布時の改名を許容するため、読込可否の必須条件にはしません。

## 6. マーカー連動

1. ホバー中のセルから、選択シート、元のExcel行番号、列番号を取得します。
2. 列番号をExcel列記号へ変換します。
3. JSONから対応するPDF座標を取得します。
4. PDF表示倍率を考慮して画面座標へ変換します。
5. 該当位置へ円と十字のマーカーを表示します。
6. マーカーが表示領域外にある場合は、PDF領域を中央付近までスクロールします。
7. 座標がないセルではマーカーを表示しません。

検索結果は元のExcel行番号を保持するため、検索後も同じレコードのPDF位置を表示します。セル編集後も、読み込み時の元行番号との関連を維持します。

## 7. 既存機能

次の機能は従来どおり使用できます。

- シート選択
- 固定2条件のAND正規表現検索
- 大文字・小文字の区別
- 直前行から変化したセルの強調
- セル全文の表示と編集
- 全シートを保持したExcel保存
- 掲載ページから電子カタログを開くリンク
- 最大5,000行の画面描画制限

## 8. エラー処理

- Excel自体を読み込めない場合は従来どおりエラーを表示します。
- PDFまたはJSONがない場合は「PDF連動なし」と表示します。
- JSON形式、座標系、PDF名、ページ番号、ページサイズが不正な場合はExcel単体モードへ戻し、状態欄に理由を表示します。
- PDF連動の失敗によってExcelの閲覧、検索、編集、保存を停止しません。
